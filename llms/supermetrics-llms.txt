- [Union nested arrays with key](https://docs.supermetrics.com/docs/union-nested-arrays-with-key.md): Transform nested arrays into a flat report with category tags using the union_nested_arrays_with_key adapter. Control inclusion with mode and keys.
- [Aggregate values](https://docs.supermetrics.com/docs/aggregate-values.md): Learn how the aggregate values adapter sums chosen fields across nested array entries to return a single total per parent item.
- [Split to rows](https://docs.supermetrics.com/docs/split-to-rows.md): Learn how the split to rows adapter splits a delimited string in an API response into separate rows, one per value.
- [Example configurations](https://docs.supermetrics.com/docs/example-configurations.md): Take a look at the example connector configurations that you can use as reference, or take and modify for your own usage with the Connector builder.
