# Supermetrics

> Supermetrics is a marketing intelligence platform that connects marketing, ecommerce, and sales data sources to business intelligence tools, data warehouses, cloud storage, and spreadsheets. Used by 200K+ companies in 120 countries to automate data transfers, reduce reporting time, and maintain SOC2/GDPR/CCPA compliance.

## Developer Tools
- [Supermetrics API](https://supermetrics.com/products/api): Supermetrics provides a RESTful API that allows developers to programmatically extract marketing data from 70+ sources and integrate it into custom applications. Returns data in JSON/CSV formats with query management capabilities

## MCP Server (for AI agents)

Supermetrics runs a remote Model Context Protocol (MCP) server that lets AI agents query 170+ marketing data sources on a user's behalf, using OAuth-authorized access.

- [MCP endpoint](https://mcp.supermetrics.com/mcp): Streamable HTTP MCP server. Unauthenticated requests return HTTP 401 with a `WWW-Authenticate` header pointing at the protected-resource metadata below.
- [Protected resource metadata](https://mcp.supermetrics.com/.well-known/oauth-protected-resource): RFC 9728 metadata naming the authorization server and supported scopes.
- [Authorization server metadata](https://mcp.supermetrics.com/.well-known/oauth-authorization-server): RFC 8414 metadata. Supports dynamic client registration (RFC 7591) and PKCE (S256).
- Authorization server: `https://api.supermetrics.com`
- Auth: OAuth 2.1, Bearer token in the `Authorization` header.
